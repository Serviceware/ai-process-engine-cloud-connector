Run on Node.js 24.22.1 to stop trusting the compromised eMudhra certificate
authorities. In October 2026 the private keys of eight eMudhra intermediate
certificate authorities were exposed, so anyone holding them can issue
certificates that look valid for any host name.

Node.js checks TLS certificates against the root certificates built into its
binary and does not check revocation, so earlier Cloud Connector images keep
trusting certificates issued with those keys. Node.js 24.22.1 removes three
emSign root certificates and rejects certificate chains that contain one of
the compromised keys. This protects the connection to the AI Process Engine
and to forwarded targets against interception by an attacker who holds one of
these keys. Update all deployments to this release.

Running the connector outside the container image now requires Node.js 24.22.1
or later.
