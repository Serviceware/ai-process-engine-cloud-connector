# Repository conventions

These documents provide the shared context for maintainers and coding agents:

- [Architecture](ARCHITECTURE.md) defines the product boundary and runtime
  design.
- [Configuration](CONFIGURATION.md) defines environment and YAML configuration
  behavior.
- [Security](SECURITY.md) records the security invariants.
- [Development](DEVELOPMENT.md) defines implementation and toolchain practices.
- [Testing](TESTING.md) defines the verification expectations.
- [Documentation](DOCUMENTATION.md) defines documentation ownership and style.
- [Pull requests](PULL_REQUESTS.md) defines the contribution and release
  workflow.

Update these conventions when an architectural or repository-wide decision
changes. Keep task-specific details close to the code or user-facing guide they
describe.
